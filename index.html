How It Works

Five steps. All inside your browser.

Drive PDF Saver is a service worker extension — it never phones home. Every request goes directly to Google's APIs.

1

Detect Active Tab & Google Account

The content script reads the current Drive/Docs URL (/u/N/ path, authuser parameter) and inspects the Google Bar profile button in the page DOM to identify exactly which Google account is active in this tab.

2

Route to the Correct Account Token

The background service worker looks up the active account in the connected accounts registry and retrieves only that account's access token from session storage. It never uses another connected account's token.

3

Verify File Access & Fetch Metadata

Drive API files.get confirms the active account can read the file and returns its name, MIME type, and parent folder ID.

4

Convert to PDF

Workspace files: files.export. Office & text files: create temporary Drive copy → export PDF → delete temp (cleanup guaranteed even on failure). Images: in-memory PDF 1.4 binary stream. The PDF is held only in RAM.

5

Save or Update in the Same Folder

files.list checks for an existing [Name].pdf in the same parent folder. Found → PATCH update in-place. Not found → multipart POST upload. An in-page toast confirms success — no duplicates.

Installation

Up and running in under 2 minutes

No Chrome Web Store. Load directly as an unpacked extension — takes less than 2 minutes.

1
Download the ZIP Click Download Extension v1.0.0 → save Drive-PDF-Saver-v1.0.0.zip anywhere on your computer.
2
Extract the ZIP Unzip it to a permanent folder, e.g. C:\Extensions\drive-pdf-saver\. Chrome loads the extension live from that folder — don't delete it later.
3
Open Chrome Extensions Navigate to chrome://extensions in your Chrome address bar.
4
Enable Developer Mode Toggle Developer mode on — the switch is in the top-right corner of the extensions page.
5
Click "Load unpacked" Select the extracted drive-pdf-saver/ folder — the one containing manifest.json.
6
Pin the Extension Click the puzzle-piece icon in Chrome's toolbar → find Drive PDF Saver → click the pin 📌 to keep it visible.
7
Click the Extension Icon → "+ Connect" A Google sign-in window will appear. Select your Google account and approve Drive access.
8
Right-Click a Drive File → Save as PDF Open any Google Doc, Sheet, Slide, Office file, or image in Google Drive. Right-click → "Save as PDF to Google Drive".

Multiple Accounts

Switch accounts as naturally as switching tabs

Drive PDF Saver maintains independent authorization for each connected Google account and routes each Drive tab to the correct token automatically.

🔗 Connecting additional accounts

  • Click the Drive PDF Saver icon to open the popup.
  • Click + Connect — a Google account picker appears.
  • Select a different Google account and approve Drive access.
  • The account appears in the Connected Accounts list.
  • Repeat for each account you want to use.

🔀 How tab routing works

  • Google multi-login URLs embed the account index: /u/0/, /u/1/…
  • The extension reads the URL path and Google Bar DOM to identify the active account.
  • The matching token is used — never another connected account's.
  • If the tab's account is not connected, a clear error prompts you to connect it. No silent fallback.

🅰️ Saving from Account A's Drive tab

  • Navigate to a file in Account A's Drive (/u/0/).
  • Right-click → Save as PDF to Google Drive.
  • The PDF is saved to Account A's Drive folder using Account A's token.

🅱️ Saving from Account B's Drive tab

  • Open a new tab, switch to Account B (/u/1/).
  • Right-click a file → Save as PDF to Google Drive.
  • The PDF is saved to Account B's Drive folder.
  • Account A's token is never touched.
ℹ️ 7-day session limit: Drive PDF Saver uses Google OAuth in Testing mode with the implicit (online) flow. Tokens cannot be silently refreshed after ~7 days of inactivity. Simply click + Connect again on the affected account to re-authorize in about 5 seconds. This is a Google Cloud Testing mode constraint.

Privacy & Security

Your files never leave Google's infrastructure

All API traffic goes directly from your browser to googleapis.com. There is no backend server — because none is needed.

🏠

No External Server

Every API call goes directly from Chrome to googleapis.com. No proxy, no relay, no middleman.

🔐

Ephemeral Tokens

OAuth access tokens live only in chrome.storage.session — in-memory RAM, automatically erased on Chrome close.

🚫

No Client Secret

Implicit OAuth 2.0 flow. No client_secret is embedded in source code or transmitted to anyone.

🗂️

Minimal Permissions

Only identity, contextMenus, activeTab, and storage browser permissions are requested.

📊

Zero Analytics

No telemetry, no crash reporting, no usage tracking of any kind — not even anonymous counters.

🧹

No Temp Files on Disk

PDF data is held in RAM only. Once uploaded to Drive, the in-memory blob is garbage collected immediately.

Troubleshooting

Common questions & fixes

"Access blocked" / "App not verified" during sign-in
Drive PDF Saver uses Google OAuth in Testing mode. Only Google accounts explicitly added as Test Users in the Google Cloud Console can authorize the app. If you see this error, contact the project owner and ask to have your Google email added as a Test User.
"No Google accounts are connected" when saving
Open the extension popup and click + Connect to authorize at least one Google account. If you have multiple Drive accounts open in different tabs, connect each one separately.
"Multiple accounts connected — active account could not be determined"
Make sure you're viewing the Drive/Docs file in a tab that shows /u/0/, /u/1/, etc. in the URL. Navigate directly to drive.google.com/u/N/ for the account you want to use so the extension can detect the correct account from the URL.
The "Save as PDF" context menu item doesn't appear
The context menu only appears on Google Drive and Docs URLs: docs.google.com/document/*, docs.google.com/spreadsheets/*, docs.google.com/presentation/*, docs.google.com/drawings/*, and drive.google.com/*. If you just reloaded the extension, refresh the document tab once to let the content script re-attach.
Will re-saving create duplicate PDFs?
No. Before uploading, Drive PDF Saver checks the same parent folder for an existing [OriginalName].pdf. If found, it updates that file's content in-place via a PATCH request — preserving the file ID and creating no duplicates. To force a fresh file, rename the original or rename the existing PDF first.
Authorization stopped working after ~7 days
In Google OAuth Testing mode, tokens from the implicit flow cannot be silently refreshed. Open the popup, click + Connect on the affected account, and re-authorize. This takes about 5 seconds. This is a Google Cloud Testing mode constraint — not a bug in the extension.
File type not supported error
Drive PDF Saver supports Google Workspace files, Microsoft Office formats (.docx, .xlsx, .pptx, .doc, .xls, .ppt), OpenDocument files (.odt, .ods, .odp), text/data files (.txt, .rtf, .html, .csv, .tsv), and images (.png, .jpg, .jpeg, .webp, .gif, .bmp). Video, audio, ZIP archives, and binary executables cannot be converted to PDF.
