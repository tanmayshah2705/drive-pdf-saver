How It Works

Five steps. All inside your browser.

Drive PDF Saver talks directly to Google Drive API v3 — no intermediary server ever touches your files.

1

Detect Active Tab & Account

The content script reads the current Google Drive/Docs URL and DOM to identify which Google account is active in this tab (via /u/N/ path, authuser query, or Google Bar profile element).

2

Route to Correct Account Token

The service worker looks up the validated session index map and returns the access token for exactly the active account — never another connected account's token.

3

Verify File Access & Fetch Metadata

Drive API files.get confirms the active account can read the file and returns its name, MIME type, and parent folder ID.

4

Convert to PDF

Workspace files: files.export. Office/text files: create a temporary Drive copy → export → delete temp. Images: in-memory PDF binary stream. The PDF is held only in RAM.

5

Save or Update in the Same Folder

Drive files.list checks for an existing [Name].pdf in the same parent folder. If found: PATCH update in-place. If not: multipart POST upload. Done — no duplicates.

Installation

Up and running in under 2 minutes

No Chrome Web Store required. Load directly as an unpacked extension in Developer mode.

Download the ZIP Click the button below to download drive-pdf-saver-v1.0.0.zip from the GitHub Release.
Extract the ZIP Unzip the downloaded file to any folder — for example C:\Extensions\drive-pdf-saver\ or ~/Extensions/drive-pdf-saver/. Keep the folder; Chrome loads it live from disk.
Open Chrome Extensions Navigate to chrome://extensions in your Chrome address bar.
Enable Developer Mode Toggle Developer mode on — it's the switch in the top-right corner of the extensions page.
Click "Load unpacked" A folder picker will open. Select the extracted drive-pdf-saver/ directory (the one that contains manifest.json).
Pin the Extension Icon Click the puzzle-piece icon in Chrome's toolbar, find Drive PDF Saver, and click the pin icon to keep it visible.
Connect Your Google Account Click the Drive PDF Saver extension icon, then click + Connect. A Google sign-in window will open — choose your Google account and approve Drive access.
Open Google Drive & Save! Navigate to any Google Doc, Sheet, Slide, Office file, or image in Google Drive. Right-click anywhere on the page and choose "Save as PDF to Google Drive".

Multiple Accounts

Switch accounts as naturally as switching tabs

Drive PDF Saver maintains an independent authorization for each connected Google account and never cross-contaminates tokens.

Connecting additional accounts

  • Click the Drive PDF Saver icon in the toolbar.
  • Click + Connect — a Google account picker appears.
  • Select any Google account (that is a registered Test User).
  • Approve Drive access. The account appears in the Connected Accounts list.
  • Repeat for each additional account.

How routing works across tabs

  • Google multi-login URLs embed the account index in the path (/u/0/, /u/1/, etc.).
  • The extension reads the active tab URL and inspects the Google Bar DOM to identify which account is currently in view.
  • The exact matching token is used — never a different connected account's.
  • If the tab's account is not yet connected, you'll see a clear error prompting you to connect it.

Tab with Account A

  • Navigate to any Drive file in Account A's view (/u/0/).
  • Right-click → Save as PDF to Google Drive.
  • The PDF is saved in Account A's Drive folder.

Tab with Account B

  • Open a new tab, sign in as Account B (/u/1/).
  • Right-click a file → Save as PDF to Google Drive.
  • The PDF is saved in Account B's Drive folder.
  • Zero interaction with Account A's token.
ℹ️ 7-day session limit: Because Drive PDF Saver uses Google OAuth in online (non-offline) mode, tokens expire and cannot be silently refreshed after 7 days of inactivity in Testing mode. Simply click + Connect again on the same account to re-authorize. This is a Google Cloud Testing mode constraint — it does not apply in Production OAuth mode.
Privacy & Security

Your files stay yours

Drive PDF Saver operates entirely between your browser and Google's official APIs. No data is ever routed through our servers — because there are none.

🏠

No External Server

All API calls go directly from your browser to googleapis.com. The extension has no backend.

🔐

Ephemeral Tokens

OAuth access tokens are stored only in chrome.storage.session — RAM only, automatically erased when Chrome closes.

🚫

No Client Secret

The extension uses implicit OAuth flow — no client secret is embedded in the code or transmitted anywhere.

🗂️

Minimal Permissions

Only identity, contextMenus, activeTab, and storage browser permissions are requested.

📊

No Analytics

No telemetry, no crash reporting, no usage tracking of any kind.

🧹

No Temp Files on Disk

PDF data is held in browser RAM only. Once uploaded to Drive, the in-memory blob is garbage collected.

Troubleshooting

Common questions & fixes

"Access blocked" / "App not verified" during sign-in

Drive PDF Saver uses Google OAuth in Testing mode. Only accounts that are explicitly added as Test Users in the Google Cloud Console can authorize the app. If you see this error, you need to be added as a Test User by the project owner.

"No Google accounts are connected" when clicking Save

Open the extension popup, click + Connect, and authorize at least one Google account. If you have multiple Drive accounts, connect each one separately.

"Multiple accounts connected and active account could not be determined"

Make sure you're viewing the Drive/Docs file in a tab that shows /u/0/, /u/1/, etc. in the URL. If the active account can't be detected from the URL, navigate to the Google Drive tab of the account you want to use (the extension reads the URL and Google Bar to identify the active account).

The "Save as PDF" context menu item doesn't appear

The menu only appears on supported Google URLs: docs.google.com/document/*, docs.google.com/spreadsheets/*, docs.google.com/presentation/*, docs.google.com/drawings/*, and drive.google.com/*. It won't appear on other websites. If you just reloaded the extension, refresh the document tab once.

The PDF already exists in Drive — will it be duplicated?

No. Drive PDF Saver checks for an existing file named [OriginalName].pdf in the same parent folder before uploading. If one is found, it updates the existing PDF's content in place instead of creating a new file. No duplicates like Report (1).pdf.

Authorization expired after ~7 days — "Please reconnect"

In Google OAuth Testing mode, tokens cannot be silently refreshed in the online/implicit flow. Re-authorize by opening the popup and clicking + Connect on the affected account. This is a Google Cloud Testing mode limitation.

File type is not supported

Drive PDF Saver supports Google Workspace files, Microsoft Office formats (Word, Excel, PowerPoint), OpenDocument files, text/data files (.txt, .rtf, .html, .csv, .tsv), and images. Video, audio, ZIP archives, and executables are not supported and will show a clear error message.
