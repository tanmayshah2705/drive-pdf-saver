Key Features

⚡ One-Click Right-Click

Select "Save as PDF to Google Drive" from the right-click menu or extension popup without ever leaving your document.

📁 Same Folder Placement

Automatically determines the original document's parent folder and saves the PDF right alongside the original.

🔄 In-Place Updating

If a PDF with the same name already exists in the folder, it updates the content in place without creating duplicate files.

📄 Universal File Support

Supports Google Docs, Sheets, Slides, Drawings, Office files (Word, Excel, PowerPoint), text files, and images.

🔒 Zero External Servers

Operates 100% client-side in your browser. All communications happen directly between your browser and Google Drive APIs.

✨ In-Page Feedback

Clean, modern in-page toast notifications keep you informed of export and upload progress without spamming your desktop.

How It Works

  1. Open any Google Doc, Sheet, Slide, Office document, or image in your browser.
  2. Right-click anywhere on the page and click "Save as PDF to Google Drive" (or open the extension popup and click the blue button).
  3. The extension queries Google Drive API directly to export/convert your document into a PDF in memory.
  4. The PDF is uploaded directly into the original file's parent folder.
  5. An in-page toast notifies you when the PDF has been successfully saved!

Privacy Policy

Effective Date: September 10, 2026

Drive PDF Saver ("the Extension") is committed to protecting your privacy. This policy explains what information is used and how it is protected.

1. Client-Side Only Architecture

Drive PDF Saver operates entirely within your Google Chrome browser. We do not own, maintain, or operate any external servers, databases, or analytics systems. No user data, files, or tokens ever leave your browser, except when communicating directly with Google's official APIs via HTTPS.

2. Google Drive Data Usage

The Extension requests access to Google Drive API solely to:

  • Identify the document open in your current tab (name, file ID, MIME type, parent folder).
  • Export or convert the document to PDF in memory.
  • Save or update the resulting PDF in the same folder as the original file.

The Extension never reads files unrelated to your explicit export action, never stores copies of your documents on disk, and never shares your data with third parties.

3. Google API Services User Data Policy Compliance

Drive PDF Saver complies with the Google API Services User Data Policy, including the Limited Use requirements. Your Google user data is never used to train machine learning or AI models, is never viewed by humans, and is never used for advertising.

4. Open Source & Source Code

Drive PDF Saver is open source under the MIT License. Anyone can inspect and verify our code on GitHub.

5. Contact

If you have any questions or feedback, please file an issue on our GitHub Issues page.
